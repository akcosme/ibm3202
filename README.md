# My Quarto Website

This project is a personal website created with **Quarto** for an assignment. The website is designed to showcase my knowledge of dashboards, Shiny Apps, and Shiny Live, while also introducing my background, skills, education, and career goals.

## Website Pages

The website includes the following four pages:

1. **Home Page**  
   Introduces who I am, including my photo, career aspirations, skills, and education.

2. **Dashboard**  
   A dashboard built in Quarto using a dataset to present data visually.

3. **Essay on Shiny Apps**  
   A lecture-note style explanation of what Shiny Apps are, how they work, and why they are useful.

4. **Essay on Shiny Live**  
   A discussion of what Shiny Live is, how it differs from traditional Shiny Apps, and its pros and cons.
